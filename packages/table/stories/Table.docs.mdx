# Key Features

- **Composable API**: Build complex layouts using semantic table primitives.
- **Interactive Behaviors**: Supports sorting, resizing, drag-and-drop, and pinning.
- **Enterprise Ready**: Optimized for dashboards, admin tools, and data-heavy applications.
- **Custom Rendering**: Easily render avatars, badges, progress bars, and actions.
- **Theme Support**: Integrated with design tokens and semantic tones.
- **Accessibility Focused**: Uses semantic table structure and keyboard-friendly interactions.

---

# Usage Guidelines

Use the `Table` component when users need to compare, scan, sort, or manage
structured data efficiently.

## Do

- Use sorting for meaningful datasets.
- Keep pinned columns minimal for readability.
- Use semantic tones consistently.
- Use sticky headers for long-scroll datasets.
- Keep row actions predictable and discoverable.

## Don’t

- Avoid enabling every advanced feature unless necessary.
- Avoid excessive sticky columns on smaller screens.
- Don’t overload rows with too many actions.
- Avoid mixing unrelated content types within the same column.

# Basic Usage

```tsx
import { Table } from "@simple-ui/table";

export const Example = () => {
  return (
    <Table
      columns={[
        { key: "name", width: "1fr" },
        { key: "email", width: "1fr" },
        { key: "role", width: "160px" },
      ]}
    >
      <Table.Head>
        <Table.Row>
          <Table.HeadCell>Name</Table.HeadCell>
          <Table.HeadCell>Email</Table.HeadCell>
          <Table.HeadCell>Role</Table.HeadCell>
        </Table.Row>
      </Table.Head>

      <Table.Body>
        <Table.Row>
          <Table.Cell>Alice Freeman</Table.Cell>
          <Table.Cell>alice@example.com</Table.Cell>
          <Table.Cell>Admin</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  );
};
```

---

# Best Practices

> [!TIP]
> Start simple and progressively enable advanced interactions like resizing,
> drag-and-drop, or pinning only when the workflow truly benefits from them.

> [!IMPORTANT]
> Sticky layouts require properly constrained parent containers with overflow
> handling for the best experience.

> [!WARNING]
> Combining resizing, dragging, sorting, and pinning simultaneously may create
> interaction overload in smaller datasets.

# Accessibility

## Keyboard Support

The table supports keyboard-accessible interactions for:

- `Tab`
- `Enter`
- `Space`

Interactive controls inside cells remain fully accessible.
