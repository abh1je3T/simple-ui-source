## Key Features

- Responsive Intelligence: Automatically calculates items per view based on container width and item minimum width
- Infinite Scroll: Seamless continuous scrolling without visual jumps
- Auto-Play: Configurable automatic scrolling with pause on hover support
- Smart Fitting: Never shows more items than specified, respects item min-width
- Touch Optimized: Native scroll behavior with CSS scroll-snap
- Accessible: Built with ARIA labels, keyboard navigation
- Lightweight: Zero dependencies beyond React

## Usage Guidelines

### Do:
- Use for product showcases, features, or content cards
- Hero banners and promotional content
- Image galleries and portfolios
- Responsive itemsPerView usage
- Mobile scroll experiences

### Don't:
- Overcrowding with too many items
- Setting unrealistic itemsPerView
- Nesting carousels
- Hiding critical content

## Usage Pattern

```tsx
import { Carousel } from "@simple-ui/components";

const products = [
  { name: "iPhone", icon: "📱" },
  { name: "iPad", icon: "📟" },
  { name: "MacBook", icon: "💻" },
];

export const ProductShowcase = () => {
  return (
    <Carousel itemsPerView={{ 0: 1, 640: 2, 1024: 3 }} gap={20}>
      {products.map((product) => (
        <div
          key={product.name}
          style={{
            height: 280,
            borderRadius: 20,
            background: "#f5f5f7",
            display: "flex",
            alignItems: "center",
            justifyContent: "center",
          }}
        >
          {product.icon}
        </div>
      ))}
    </Carousel>
  );
};
```
