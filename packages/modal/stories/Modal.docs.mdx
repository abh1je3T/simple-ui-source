## Key Features

- **Focus Management**: Automatically traps focus within the modal and restores it on close.
- **Scroll Locking**: Prevents background scrolling while the modal is active.
- **Multiple Tones**: Supports semantic tones like `primary`, `secondary`, and `tertiary`.
- **Responsive Sizing**: Offers various size variants (`sm` to `xl`) for different content volumes.
- **Safe Dismissal**: Supports closing via backdrop click or the Escape key.

---

## Usage Guidelines

### Do:
- **Use for Focal Tasks**: Use modals for specific tasks that need to be completed before the user returns to the main flow.
- **Keep it Simple**: Try to limit the complexity of the content within a modal to avoid overwhelming users.
- **Provide Clear Actions**: Always include clear "Cancel" and "Confirm" (or equivalent) actions in the footer.

### Don't:
- **Nested Modals**: Avoid opening a modal on top of another modal; it complicates focus management and UX.
- **Overcrowd**: Don't use modals for large amounts of information that would be better suited for a dedicated page.
- **Implicit Closure**: Avoid making critical tasks closable only via backdrop click; always provide an explicit close action.

## Usage Pattern

```tsx
import { Modal } from "@simple-ui/modal";
import { Button } from "@simple-ui/button";
import { useState } from "react";

const Example = () => {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Open Modal</Button>
      <Modal 
        open={open} 
        onClose={() => setOpen(false)} 
        title="Account Settings"
      >
        <div style={{ display: 'flex', flexDirection: 'column', gap: 16 }}>
          <p>Manage your account preferences here.</p>
          <div style={{ display: 'flex', justifyContent: 'flex-end', gap: 8 }}>
             <Button variant="secondary" onClick={() => setOpen(false)}>Close</Button>
             <Button variant="primary" onClick={() => setOpen(false)}>Save</Button>
          </div>
        </div>
      </Modal>
    </>
  );
};
```

## Best Practices

> [!TIP]
> **Size Selection**: Use `size="sm"` for simple confirmations and `size="lg"` or `xl` for complex forms to ensure readable line lengths and adequate spacing.

> [!IMPORTANT]
> **Accessibility**: Ensure the `title` prop is descriptive, as it is used to provide the accessible name for the dialog for screen reader users.

- **Keyboard Support**: Fully supports navigation via `Tab`, and dismissal via `Esc`.
- **Focus Management**: Focus is trapped and managed automatically upon opening and closing.
